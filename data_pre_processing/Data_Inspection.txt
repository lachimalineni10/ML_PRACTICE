🔍 **Step 2: Data Inspection**

📌 **Definition**
Data inspection is the process of exploring and understanding the structure, types, and quality of your data.

🧠 **Why It’s Important in ML**
- Helps identify missing values, data types, strange entries, and outliers.
- Guides you in deciding what cleaning or transformation steps are needed.

🐍 **Python Methods to Use**
| Method               | Purpose                                            |
|----------------------|----------------------------------------------------|
| `df.head()`          | View first 5 rows (you’ve already used this)       |
| `df.info()`          | Summary of columns, non-null count, and data types |
| `df.describe()`      | Statistical summary of numeric columns             |
| `df.columns`         | List all column names                              |
| `df.shape`           | Get number of rows and columns                     |
| `df.dtypes`          | Show the data types of each column                 |
| `df.isnull().sum()`  | Count missing (null) values per column             |
| `df.nunique()`       | Count of unique values per column                  |

✍️ **Example Code to Run in Your Notebook**
```python
# Show structure and data types
print(df.info())

# Summary statistics (only numerical columns)
print(df.describe())

# Check for missing values
print(df.isnull().sum())

# Shape of the dataset (rows, columns)
print("Shape:", df.shape)

# List of column names
print("Columns:", df.columns.tolist())
```

📌 **What to Look for in the Output**
- Columns like `Cabin` might have lots of missing values → needs cleaning.
- `Age` might have missing values too → needs imputing or removal.
- `Survived`, `Sex`, `Embarked` are likely categorical → needs encoding later.
- `Fare`, `Age`, `Pclass` are numeric → might need scaling/normalization later.
