Linear Algebra for ML
Linear algebra is the branch of mathematics that deals with vectors, matrices, and linear transformations. It's widely used in machine learning to manipulate data and model learning algorithms.

Key Concepts:
1️⃣ Scalars
A scalar is a single number, 
such as 5, -3, or 3.14.

2️⃣ Vectors
A vector is a one-dimensional array of numbers.
Example:
        v = [1, 2, 3]

3️⃣ Matrices
A matrix is a two-dimensional array of numbers. 
Example:
        A = [[1, 2, 3],
            [4, 5, 6]]

4️⃣ Matrix Operations
Common matrix operations include addition, subtraction, and multiplication.

Addition
Matrix addition is performed element-wise:
        A = [[1, 2],
            [3, 4]]

        B = [[5, 6],
            [7, 8]]

        A + B = [[1+5, 2+6],
                [3+7, 4+8]]

            = [[6,  8],
                [10, 12]]

5️⃣ Dot Product
The dot product of two vectors is the sum of the product of their corresponding elements.

Example:
        v1 = [1, 2]
        v2 = [3, 4]

        Dot product = (1×3) + (2×4) = 3 + 8 = 11

6️⃣ Matrix Transpose
The transpose of a matrix flips its rows and columns.

Example:
        A = [[1, 2, 3],
            [4, 5, 6]]

        Transpose of A:

        A^T = [[1, 4],
            [2, 5],
            [3, 6]]
