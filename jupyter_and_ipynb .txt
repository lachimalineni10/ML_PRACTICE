📚 What is an .ipynb File?
💡 Definition:
.ipynb stands for IPython Notebook.

It’s a JSON-based file format that contains code cells, markdown cells, and their output.

Used mainly with Jupyter Notebooks to write and execute Python code interactively.

📂 Structure of an .ipynb File:
Contains multiple cells:

Code Cells: For writing and running Python code.

Markdown Cells: For adding formatted text, headings, and explanations.

Output: Displays the results or errors after executing a cell.

🎯 How Jupyter Works in VS Code
➡️ Opening a Notebook
Open any .ipynb file, and VS Code automatically switches to the Jupyter Notebook interface.

🚀 Jupyter Notebook Toolbar in VS Code
🛠️ Toolbar Options:
▶️ Run Cell

Runs the selected cell.

Shortcut: Shift + Enter to run and move to the next cell.

⏩ Run All

Executes all cells in the notebook.

Useful when restarting the kernel or running the whole notebook.

🧠 Restart Kernel

Restarts the Python kernel, clearing all variables and outputs.

Use this if your notebook is stuck or giving unexpected results.

📄 Add Code/Markdown Cell

Adds a new cell below the selected cell.

Select between Code and Markdown from the dropdown.

💾 Save Notebook

Saves the notebook and all outputs.

🔄 Clear Output

Clears the output of the selected or all cells.

📢 Important Shortcuts:
Shift + Enter → Run current cell and move to next.

Ctrl + Enter → Run current cell but stay in the same cell.

A → Insert cell above.

B → Insert cell below.

D, D → Delete selected cell.

🎯 Where is the Kernel in VS Code?
The Kernel is the Python interpreter that runs your code.

Located in the top right of the Jupyter interface in VS Code.

If you need to change the environment:

Click on the kernel name.

Select the desired environment or interpreter.
